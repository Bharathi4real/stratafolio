# Changelog

## 1.0.0

First public release.

- Portfolio with a home page builder: hero with an ember shader, about, case studies, experience, toolkit, blog teaser and contact sections.
- Standalone blog with search, filters, scheduling, table of contents, related posts and generated covers.
- Admin with autosave, a review panel, version history with diffs, Markdown import, media library with a bin, roles and invite-only sign-in.
- SEO: structured data, generated share images, sitemap, robots.txt, llms.txt and IndexNow.
- Privacy-first, cookieless stats with an optional consent banner.
- Read-only demo mode (`DEMO_MODE=1`).
- Runs on free tiers: Vercel, Neon, Cloudflare R2 and Resend.
